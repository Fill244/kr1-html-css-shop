# Учебный frontend-проект (kr1-html-css-shop)

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — карточка товара с таблицей характеристик;
- `order.html` — форма заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Используемые технологии

- HTML;
- CSS;
- JavaScript (минимально, для модального окна и формы);
- Git;
- GitHub.

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке;
- страница карточки товара `product.html` с таблицей характеристик;
- страница заявки `order.html` с формой (имя, e-mail, телефон, тема, комментарий, согласие);
- единое меню на всех страницах и якорные ссылки (`#advantages`, `#popular`, `#contacts`);
- карточки товаров с бейджами.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`, `:active`;
- позиционирование: `relative` (карточка товара), `absolute` (бейдж), `sticky` (шапка и фильтр каталога), `fixed` (кнопка «Наверх»), `z-index` (шапка, кнопка, модальное окно);
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта;
- `product-details` — блок карточки товара на странице `product.html`;
- `product-table` — таблица характеристик;
- `reviews-grid`, `review-card` — блок отзывов;
- `faq` — блок часто задаваемых вопросов;
- `to-top` — фиксированная кнопка «Наверх».

Модификаторы карточки товара: `product-card--featured`, `product-card--new`, `product-card--discount`, `product-card--unavailable`.

## Как посмотреть проект

1. Открыть ссылку GitHub Pages: https://Fill244.github.io/kr1-html-css-shop/ или открыть файл `index.html` в браузере.
2. Проверить переходы между страницами через меню: главная, каталог, карточка товара, заявка, контакты.
3. Проверить якорные ссылки: «Преимущества», «Популярные товары», «Обратная связь».
4. На главной нажать «Заказать» в карточке товара и проверить модальное окно.
5. Открыть каталог и проверить карточки и фильтр.
6. Открыть страницу товара и проверить таблицу характеристик.
7. Открыть страницу заявки и проверить форму.
